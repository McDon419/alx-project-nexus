# ALX Project Nexus Documentation Hub

Welcome to the **ALX Project Nexus** documentation hub.  
This repository serves as the central source of truth for project setup, workflows, and resources.

---

## Project Overview
The capstone project is an **E-commerce Catalog Platform** built with **Next.js** as a web app (PWA-ready).  
It provides hands-on experience in building scalable, production-ready applications with modern frontend technologies.

- **App Repository:** [`alx-project-nexus-app`](https://github.com/McDon419/alx-project-nexus-app)  
- **Docs Repository (this repo):** `alx-project-nexus`

---

## Tech Stack
- **Framework:** Next.js (Web + PWA)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **State Management:** Context API (with potential Redux extension)
- **Deployment:** Vercel
- **Version:** Node.js 18 (LTS recommended)
